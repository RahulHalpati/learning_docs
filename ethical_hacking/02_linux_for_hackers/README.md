# Section 02 · Linux for Hackers

> All the tools in Section 03 are Linux commands. Before you can use them, you need to be
> comfortable navigating a Linux system, reading files, and understanding permissions. This
> section covers exactly what you need — no more, no less.

| Module | What you'll learn | Time |
|---|---|---|
| [01 Terminal survival](01_terminal_survival.md) | Navigation, man pages, pipes, redirection, the commands you'll use every day | ~1 h |
| [02 Files, permissions & users](02_files_permissions_users.md) | chmod, SUID/SGID bits, /etc/passwd, /etc/shadow, privilege escalation surface | ~1.5 h |
| [03 Networking commands](03_networking_commands.md) | ip, ss, netstat, ping, traceroute, dig, curl — verified inside the attacker container | ~1.5 h |
| [04 Process & service management](04_process_and_service_management.md) | ps, top, kill, systemctl, cron — find and kill suspicious processes | ~1.5 h |
| [05 Bash scripting basics](05_bash_scripting_basics.md) | Variables, loops, conditionals — write your first recon automation script | ~1.5 h |
