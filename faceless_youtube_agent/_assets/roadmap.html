The engine question

Why LangGraph — and where Google ADK fits

You asked to compare both before committing. Module 01-2 does the full side-by-side; here's the verdict. Both are capable and model-agnostic — the pick is about friction and transfer.

this course LangGraph

An explicit graph of state → nodes → edges. You're already learning LangChain, a video pipeline is an explicit graph, and its interrupt_before gate gives you "approve before rendering" in one argument. Biggest tutorial ecosystem.

also great Google ADK

Composed agents — Sequential/Parallel/Loop. Reach for it when you're on Google Cloud, want managed deployment via Vertex AI Agent Engine, or are standardising on Gemini. The concepts you learn here carry straight over.

The design lesson

Runs now · upgrades later — one node at a time

Everything runs offline today. Each "real" upgrade is a single-node change; the graph, the state, and every other node stay identical. That swap-ability is the whole point.

NodeRuns now (offline)Real upgrade
LLMfake / local OllamaClaude · OpenAI
Voiceoverffmpeg track sized to reading timepyttsx3 · edge-tts · Piper · ElevenLabs
VisualsPillow slidesSDXL images · stock B-roll
Videoreal h264/aac .mp4same, at 1080p / 4K
Upload— (needs OAuth)YouTube Data API v3

Prove your setup in 60 seconds

Quick start

No API key. Produces a real out/<slug>/video.mp4 and passes the tests.

# in 99_project_faceless_studio/
pip install -r requirements.txt        # + system ffmpeg

# offline demo — canned model + silent narration, still a REAL mp4
STUDIO_LLM=fake python -m faceless_studio.cli "Big-O notation for beginners"

python -m pytest -q                    # 7 passed

# real local model (ollama pull qwen2:7b)
STUDIO_LLM=ollama python -m faceless_studio.cli "Why RAM is faster than a hard disk"

Build it to learn and to speed up honest work — not to spam. YouTube requires you to disclose AI-generated content and doesn't monetise mass-produced, repetitive uploads. The pipeline is designed for it: it stops at a finished file, upload is a separate private-by-default step, and there are two human gates. Your editorial judgement is the moat.
