# Section 03 · Functions & Modules

> **Level:** Beginner → Intermediate · **Prerequisites:** [Section 02](../02_data_structures/README.md)
> **Time:** ~6 hours · **Verified:** 2026-06-04 (Python 3.12.13)

Up to now your programs run top to bottom in one file. That doesn't scale. **Functions** let you name and reuse a piece of logic; **modules and packages** let you split a program across files; **type hints** make intent explicit; **virtual environments and pip** let you install other people's code; and the **standard library** gives you batteries-included tools. This section turns "scripts" into "software."
