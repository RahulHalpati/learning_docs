# Section 02 · Data Structures

> **Level:** Beginner · **Prerequisites:** [Section 01](../01_fundamentals/README.md)
> **Time:** ~5 hours · **Verified:** 2026-06-04 (Python 3.12.13)

Single values only get you so far. Real data comes in *collections*: a list of orders, a record of a user, a set of tags. This section covers Python's four built-in collection types and the comprehension syntax that makes transforming them a joy.

## Choosing the right structure (quick guide)

| Need | Use |
|------|-----|
| An ordered, editable sequence | **list** `[ ]` |
| A fixed group of values that won't change | **tuple** `( )` |
| Look something up by a name/key | **dict** `{key: value}` |
| Unique items / fast "is it in here?" | **set** `{ }` |
