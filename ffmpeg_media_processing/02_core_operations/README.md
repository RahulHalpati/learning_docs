# 02 · Core operations

> **Level:** Beginner → Intermediate · **Prerequisites:** [01 · Foundations](../01_foundations/README.md)
> **Time:** ~2.5 hours

The four operations that make up most real media work: convert, cut, join, and extract audio. Each one has a fast path and a correct path, and knowing which you need is the whole skill.

| # | Module | You'll be able to… |
|---|--------|--------------------|
| 1 | [Converting & remuxing](01_converting.md) | Change format without needlessly re-encoding; avoid generation loss |
| 2 | [Trimming & cutting](02_trimming_and_cutting.md) | Cut frame-accurately, and know when the fast cut lies to you |
| 3 | [Concatenating](03_concatenating.md) | Join clips with the demuxer or filter, and pick the right one |
| 4 | [Extracting audio](04_extracting_audio.md) | Produce exactly the audio format speech-to-text needs |
