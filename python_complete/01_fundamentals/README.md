# Section 01 · Fundamentals

> **Level:** Absolute beginner · **Prerequisites:** [Introduction](../00_introduction.md)
> **Time:** ~8 hours · **Verified:** 2026-06-04 (Python 3.12.13)

This is the bedrock. By the end you can install Python, run code, store and manipulate values, make decisions, and repeat work. Everything else in the course stands on this.

A small interactive command-line program — for example a number-guessing game or a tip calculator — using input, decisions, and loops.
