# 🗄️ Inventory Data Engineering & Analytics

> **Level:** Intermediate · **Prerequisites:** [Network Inventory Management](../network_inventory/) (recommended).

The advanced companion to the [Network Inventory](../network_inventory/) primer. This guide builds a full **inventory data pipeline**: design a relational schema, expose it through APIs, move data with ETL, migrate to a **graph database**, query it, and finish with ML and graph analytics. A practical tour of modern data architecture through one consistent domain.
