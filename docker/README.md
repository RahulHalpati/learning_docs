# 🐳 Docker — from first principles to a Dockerized FastAPI app

> **Level:** Absolute Beginner · **Prerequisites:** none — just a computer and curiosity.

A hands-on Docker course that starts with *what a container even is* and ends with you containerizing a complete FastAPI application, complete with multi-stage builds, security scanning, and a CI/CD pipeline. No prior DevOps experience needed.

## Lessons

| # | Lesson | What you'll learn |
|---|--------|-------------------|
| 00 | [Introduction to Docker](00_introduction.md) | What Docker is, why it exists, containers vs VMs, installation |
| 01 | [Core Concepts](01_core_concepts.md) | Images, containers, and your first Dockerfile |
| 02 | [Dockerfile Deep Dive](02_dockerfile_deep_dive.md) | Multi-stage builds, BuildKit, image optimization |
| 03 | [Networking & Volumes](03_networking_and_volumes.md) | Container communication and persistent data |
| 04 | [Docker Compose](04_docker_compose.md) | Multi-container apps with one command |
| 05 | [Security & Docker Scout](05_security_and_docker_scout.md) | Scanning images, handling secrets, hardening |
| 06 | [CI/CD & Production](06_cicd_and_production.md) | Pipelines, monitoring, health checks |
| 07 | [Practical Project](07_practical_project.md) | Dockerize a complete FastAPI application end to end |
