## What is Network Inventory Management?

**In Simple Terms:**  
Network Inventory Management is like keeping a detailed, up-to-date map and catalog of every piece of equipment (routers, cables) and service (internet connections) in a telecommunications network.

**Real-World Example:**  
Think of a public library. The library's catalog system (the inventory) tracks every book (resource), who borrowed it, and where it belongs on the shelf. If the catalog is wrong, you can't find the book. In a telecom network, if the inventory is wrong, you can't fix outages or add new customers.

**Why Learn This:**
- Career: Telecom and cloud companies desperately need experts to manage their massive, complex networks.
- Practical: You'll learn how to organize massive amounts of interconnected data.
- Skills: Data modeling, Graph concepts, Telecom standards (TMF).

## Key Terms
- **Resource:** A physical or logical piece of the network (e.g., a router, a fiber optic cable, an IP address).
- **Service:** What the customer actually buys or uses (e.g., High-Speed Internet, a VPN connection).
- **TMF (TM Forum):** An alliance that creates standards so different telecom software can talk to each other.
