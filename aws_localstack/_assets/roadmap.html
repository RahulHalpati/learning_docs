The one trick

Override the endpoint → :4566

Point any AWS tool at LocalStack with one setting and dummy creds. Remove it and the identical code talks to real AWS.

boto3awslocalOpenTofu aws ──▶ LocalStack · localhost:4566

Local ↔ real AWS

Same code — one setting flips the target

# LocalStack: set the endpoint
export AWS_ENDPOINT_URL=http://localhost:4566
s3 = boto3.client("s3", endpoint_url=os.environ.get("AWS_ENDPOINT_URL") or None)

# real AWS: unset it → endpoint_url=None → default endpoints
# (and delete the endpoints{} block in the OpenTofu provider)

Real gotcha this course hit: LocalStack's 2026 CLI refuses to start without a free account token. The fix — pin the token-free community image localstack:3.8.1 — keeps the whole course (and CI) signup-free and reproducible.
