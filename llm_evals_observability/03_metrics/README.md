# Section 03 · Metrics

> **Prerequisites:** [02 · Datasets](../02_datasets/README.md) · **Time:** ~2 h

What to actually measure. Deterministic metrics first (cheap, reproducible, defensible), then the semantic ones — and, critically, when each lies to you.

## What you'll be able to do after this section

- Implement and interpret exact match, containment, token F1, Jaccard.
- Know when a metric misleads (and why you always use several).
- Pick metrics that match the task rather than what's easy to compute.
