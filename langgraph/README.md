# 🕸️ LangGraph — stateful LLM agents with graphs

> **Level:** Absolute Beginner · **Prerequisites:** basic Python; familiarity with LLMs helps but isn't required.

LangGraph lets you build LLM applications as **graphs** — nodes that do work, edges that decide what happens next, and a shared state that flows through it all. This course explains the model from the ground up and finishes with a working research-assistant agent.

> Pairs well with the **[LangChain & RAG](../langchain_rag/)** guide (LLM building blocks) and leads into the **[F&O Trading Bot](../langgraph_fo_trading_bot/)** project.
