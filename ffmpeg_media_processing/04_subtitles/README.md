# 04 · Subtitles & captions

> **Level:** Intermediate · **Prerequisites:** [03 · Filters](../03_filters/README.md)
> **Time:** ~1.5 hours

Most social video is watched muted. Captions aren't an accessibility afterthought there — they're the primary channel, and the difference between a clip that holds attention and one that gets scrolled past.

This section covers the formats, then how to render them permanently into the picture.
