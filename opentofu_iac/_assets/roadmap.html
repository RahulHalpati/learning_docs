The mental shift

Declare the destination, not the steps

Imperative (a script)

You write the steps. Run it twice and it may fail or duplicate. Drift is invisible.
create X; then Y; then Z

Declarative (OpenTofu)

You write the desired state. Run it twice → No changes. plan shows the diff before anything happens.
this container should exist

The collection comes together

Audit → integrate & deploy → provision

Three courses, one path from a commit to running software on infrastructure you declared.

# Secure Code Audit → find vulns in the source
codeaudit / bandit / pip-audit

# CI/CD → test, scan, build the image, deploy
docker build -t linkstash .   →   ci.yml · cd.yml

# OpenTofu (here) → provision where it runs
tofu apply    # network + image + container → app on :8088

Two real bugs this capstone caught: a child module needs its own required_providers source (or init fails on hashicorp/docker), and docker build --load is needed or the provider tries to pull the local image. Both surfaced by reading the error and the plan.
