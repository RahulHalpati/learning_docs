# 05 · Encoding & quality

> **Level:** Intermediate → Advanced · **Prerequisites:** [04 · Subtitles & captions](../04_subtitles/README.md)
> **Time:** ~2 hours

Every ffmpeg command in this course ends by encoding something. This section is about doing that deliberately: choosing a quality target, understanding what you're trading away, and knowing which knobs actually matter.

All numbers here are measured on a 1280×720 30 fps source, with PSNR against the lossless original.
