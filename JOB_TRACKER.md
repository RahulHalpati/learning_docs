## Readiness gate — what unlocks the $30k+ band

Don't apply to the good roles until these are ticked. Each one is a bullet on the résumé that the ₹12 LPA crowd doesn't have.

- [ ] **One deployed GenAI app** with a public URL and a README that shows the architecture ([capstone](3_MONTH_GENAI_SPRINT.md))
- [ ] **An MCP server** you built and published — the scarce 2026 skill, almost nobody at 3 YOE has this
- [ ] **An eval suite** on the capstone with numbers in the README (`llm_evals_observability`) — this is what separates "used LangChain" from "shipped LLM systems"
- [ ] **RAG pipeline** you can whiteboard end to end: chunking → embed → retrieve → rerank → generate, and why each choice
- [ ] GitHub profile README pointing at the above, pinned repos, green-ish commit graph
- [ ] LinkedIn headline rewritten: `AI Engineer · LLM apps, RAG, MCP · Python/FastAPI` (not "Software Developer at X")
- [ ] Résumé rewritten around *shipped systems*, not responsibilities. One page.

## Negotiation notes

- $30k is your **floor, not your ask**. Market data puts 2–4 YOE remote GenAI at $30–55k from foreign employers; production LLM experience is the top band. Never name a number first.
- Anchor in **USD**, never INR. The moment you say "₹X lakh" you get benchmarked against the Indian market instead of the remote one.
- Contract math: $30k/yr FTE ≈ $15/hr — far too low for contract, where you carry taxes and no benefits. Contract floor is **$30/hr**, and Mercor-tier AI work already pays $50/hr.
