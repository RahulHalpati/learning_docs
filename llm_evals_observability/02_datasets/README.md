# Section 02 · Datasets

> **Prerequisites:** [01 · Foundations](../01_foundations/README.md) · **Time:** ~1.5 h

Your eval is only as good as its dataset. This section covers building a golden set from nothing, and — the part that actually matters long-term — growing it from production traces.

## What you'll be able to do after this section

- Write a golden dataset with references, tags, and deliberate edge cases.
- Cover the categories that matter (happy path, edge, adversarial, out-of-scope).
- Turn a production failure into a regression test.
